## Work files (foreman)

- Do not create work files (drafts, notes, scratch, mockups, research) in this repository. Run `foreman work new <topic>` and put them in the folder it prints.
- Do not read other agents' work folders unless you were given the path.
- Report problems you notice with `foreman report "<what happened>"` (a rule for this project: `foreman report --project "<rule>"`).
- Report stage changes of your task with `foreman stage <stage>`.
